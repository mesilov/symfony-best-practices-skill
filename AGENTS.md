# Repository instructions

This repository publishes `skills/symfony-best-practices/`, an agent skill for Symfony applications. It is not itself a Symfony application.

For repository maintenance, source/provenance updates, package checks and releases, read `.agents/skills/symfony-skill-maintainer/SKILL.md` and only the relevant linked procedures. That is the canonical repository-only skill; `.codex/skills/` and `.claude/skills/` expose relative aliases.

Keep agent instructions and references in English; preserve the current README's language and style. Use the declared Python dependencies and existing validation/build commands. Preserve unrelated checkout work and historical verification evidence. Release scope follows the user's request; adding or updating instructions does not itself authorize publishing.

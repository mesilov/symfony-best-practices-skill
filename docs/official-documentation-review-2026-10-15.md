# Обзор официальной документации Symfony

Дата: 2026-10-15. Задача: дополнить эталон 0.1.0 ключевыми рекомендациями из всех 43 заданных ссылок, сохранив семь групп и короткий SKILL.md. Версия пакета остается 0.1.0; число references изменено с 18 до 31.

## Источники и версия

На дату проверки `current` соответствует линии 8.1: [официальные релизы](https://symfony.com/releases). Framework source закреплен на `symfony/symfony-docs`, branch 8.1, commit `9162aaaa515256a0ceeab6b98e313e9d1dcb89fe`. Три AI страницы берутся из `symfony/ai`, commit `5ad77d9418152e61e5b2b2bbb29d070a07fc2a67`. Версии AI компонентов/bridges определяются отдельно по composer.lock. Проверенные рекомендации для 8.0 сохранены с явной маркировкой; автоматический upgrade не подразумевается.

40 документов = 37 framework pages + 3 AI pages. Security представлен четырьмя пользовательскими URL одной страницы: сама страница и anchors `the-user`, `the-firewall`, `access-control-authorization`. В provenance сохраняются все 43 исходные URL, source paths, SHA-256, цели и лицензии. Полные руководства и их code examples не включены в пакет. Symfony Docs — CC BY-SA 3.0, Symfony AI — MIT; attribution и license hashes сохранены.

## Что добавлено

13 новых справочников: routing/HttpKernel; DI/events/Kernel; Twig/Translation; sessions; logging/error pages; Mailer/Notifier; Serializer; HttpClient/webhooks; Workflow/Lock; Filesystem/UID/YAML/ExpressionLanguage; deployment/performance/HTTP cache; AI Mate; AI/MCP integration. Расширены существующие configuration/testing/forms/security/Doctrine/cache/Messenger/Scheduler. Список компонентов не является требованием устанавливать их все.

Рекомендации задают решения, failure modes и границы проверки. Адресные ограничения включают main/subrequests и shared state, session/private cache, HttpClient lazy exceptions и timeout budgets, raw-byte webhook signatures, delivery versus queue acceptance, Workflow concurrency, lease loss, FPM/OPcache restart и недоверенные AI tool/retrieval данные. Детали и решения O23–O36 приведены в [source review](source-review.md).

## Проверка полноты

Schema 3 требует именно выбранные 40 identities и 43 URL, SHA-формат, точные paths/репозитории, source URLs на full commit, license metadata и существующие reference targets. `--docs-checkout symfony-docs=... --docs-checkout symfony-ai=...` дополнительно сверяет фактические HEAD и hashes; offline проверка ничего не скачивает. Combined donor/documentation map покрывает все 31 references. [Тесты](../tests/test_documentation.py) проверяют потерю страницы/URL, неверную версию/commit/hash/path/target/license, удаление/изменение AI MIT notice и потерю framework attribution.

До правок независимый агент прочитал прежний пакет для C1–C6 и нашел частичное покрытие C1–C5 и отсутствие адресного AI coverage C6. Это оценка текста, а не провалы модели: часть конкретных решений агент предложил из собственных знаний. Повторная оценка новых references и итоговые package checks фиксируются в [verification](verification-0.1.0.md). Symfony-приложение, DB, broker, HTTP/provider или AI endpoint этим обзором не запускались.
